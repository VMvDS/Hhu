TriLauncher v3 (By Mr Amr)

Build: upload this folder to a GitHub repository, open Actions > Build APK > Run workflow, download TriLauncher-APK.
Customize: long-press an empty spot on the home screen, or double-tap (Layout, Wallpaper, Home shortcuts, Hidden apps, Icon style, Photo dimming, Gestures).

STATUS (nothing below has been compiled or run on a device)
Written, untested: HOME launcher intent, app discovery, app launching, drawer with search and blur, two layouts
(Dark Coast, Black Hole), custom line-icon family, wallpaper picker + own photo, hide apps, pin to home,
swipe up/down and double-tap gestures, saved settings, depth-zoom effect when the drawer opens.
Not implemented: widgets (AppWidgetHost), Jetpack Compose (plain Views used), drag-and-drop layout editing,
Monochrome Minimal and Crimson Editorial layouts (reference photos not received), release AAB and signing,
real parallax, weather.
Not verified: notification-shade swipe-down (uses a hidden API, may be blocked on newer Android).
